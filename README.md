# SPOT Group

Editorial real estate website for SPOT Group — Nav Sidhu, Lower Mainland real estate
consultant and licensed builder. Next.js App Router, TypeScript, Tailwind.

Brand: black `#000000`, white `#FFFFFF`, SPOT yellow `#FFBF00`. The mark is the
21-dot triangle, drawn inline in `src/components/brand/spot-mark.tsx` (transparent,
`currentColor`, optional `mirrored`).

## Routes

| Route | Purpose |
| --- | --- |
| `/` | Cinematic hero + search, overlap intro panel, featured carousel, communities, selling, developments, pillars, stats, team, insights, CTA |
| `/buy` | Full search: keyword/MLS®, community, city, type, price, beds, baths, open houses, sort, list/map, mobile filter drawer, filter pills |
| `/buy/featured`, `/buy/recently-listed`, `/buy/open-houses` | Curated listing views |
| `/listings/[slug]` | Gallery + lightbox, stats, description, features, open houses, map, neighbourhood, agent card, showing form, similar properties, sticky mobile CTA |
| `/exclusive` | Off-market inventory + buyer-list registration |
| `/sell` | Selling process, `#valuation` request, `#cash-offer` as-is intake |
| `/new-developments`, `/new-developments/[slug]` | Project index and detail with registration |
| `/communities`, `/communities/[slug]` | Community index and template (overview, lifestyle, schools/parks/shopping/transit, inventory, related reading) |
| `/team`, `/team/[slug]` | Team index and profiles |
| `/about`, `/contact` | Company positioning and enquiries |
| `/insights`, `/insights/[slug]`, `/insights/category/[category]` | Guides and market notes |
| `/privacy`, `/terms`, `/accessibility` | Legal and disclosures |
| `/sitemap.xml`, `/robots.txt` | Generated by `src/app/sitemap.ts` and `robots.ts` |
| `/api/listings`, `/api/leads` | Search endpoint and lead intake |

## Listing data — demonstration only

Listings are served through the `ListingsProvider` interface in
`src/lib/listings/provider.ts`. The site runs on `DemoListingsProvider`
(`src/lib/listings/demo-data.ts`), which is **realistic sample inventory, not live
MLS® data**. `/buy` says so on the page; keep that notice until a licensed feed is
connected.

To go live you need a licensed feed — CREA's Data Distribution Facility (DDF®) or a
Greater Vancouver / Fraser Valley board IDX feed. Once credentials exist:

1. Implement `DdfListingsProvider` against the RESO Web API (including `similar()`).
2. Return it from `getListingsProvider()` when `LISTINGS_PROVIDER=ddf`.
3. Set the DDF environment variables (see `.env.example`).
4. Remove the demonstration notices on `/buy` and in the footer.

Pages and components consume the `Listing` type only, so nothing else changes.

## Leads

All forms `POST` to `/api/leads`. Leads are validated in `src/lib/leads.ts`, written
as newline-delimited JSON to `LEADS_FILE` (default `./data/leads.jsonl`) and, when
`LEADS_WEBHOOK_URL` is set, forwarded to a CRM or automation endpoint.

**There is no production inbox or CRM connected yet.** Set `LEADS_WEBHOOK_URL`, or
replace `saveLead`, before launch — otherwise submissions only land in the local file.
